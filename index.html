    How to set up ComfyUI (one time)
    1. Install ComfyUI Desktop for Windows. When it asks for your GPU, pick AMD (ROCm). If AMD recommends a driver during setup, install it.
    2. Download these 3 files (about 16 GB) and put them in your ComfyUI models folder:
      • wan2.2_ti2v_5B_fp16.safetensors → models/diffusion_models
      • umt5_xxl_fp8_e4m3fn_scaled.safetensors → models/text_encoders
      • wan2.2_vae.safetensors → models/vae
    3. Let this page talk to ComfyUI: in ComfyUI Desktop open Settings → Server Config and set Enable CORS header to *, then restart ComfyUI. (Portable or manual installs: start ComfyUI with --enable-cors-header "*".)
    4. Copy the address ComfyUI shows (Desktop usually uses http://127.0.0.1:8000, manual installs http://127.0.0.1:8188) into the box above and press Check. If the browser asks to allow access to devices on your local network, choose Allow.
